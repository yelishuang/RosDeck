## 1. 项目概述

### 1.1 产品定位

**RosDeck** 是一个自托管的 Web 控制面板，专为本地网络中的 ROS 2 设备设计。它提供了完整的系统监控、网络管理、存储维护、进程控制以及 ROS 生态系统管理功能，旨在为开发者和运维人员提供一站式的设备管理解决方案。

### 1.2 核心特性

- **实时监控**: CPU、内存、磁盘、网络实时状态监控
- **文件管理**: 文件上传、下载、删除，支持管理员全局访问
- **Web终端**: 基于 xterm.js 的交互式命令行终端
- **日志查询**: journalctl 集成，支持过滤、搜索、分页加载
- **网络管理**: 网络接口监控、流量统计、IP配置、网络诊断
- **存储维护**: 磁盘监控、清理、挂载、格式化、SMART检测
- **进程管理**: 进程列表、终止进程、systemd 服务管理
- **ROS 集成**: 节点监控、话题分析、参数管理、数据录制

### 1.3 技术栈

- **前端框架**: jQuery + Bootstrap 5
- **图表库**: Chart.js
- **终端组件**: xterm.js
- **通知组件**: Toastr
- **图标库**: Bootstrap Icons
- **构建方式**: 原生模块化加载（无构建工具）

## 2. 全局功能

### 2.1 页面布局

RosDeck 采用经典的三栏布局：

```
┌─────────────────────────────────────────────────┐
│            顶部状态栏（Status Ribbon）            │
├──────┬──────────────────────────────────────────┤
│      │              顶部导航栏                   │
│      ├──────────────────────────────────────────┤
│ 侧边栏│                                          │
│      │           主内容区                        │
│      │      （动态加载模块）                      │
│      │                                          │
└──────┴──────────────────────────────────────────┘
```

### 2.2 顶部状态栏

**位置**: 页面最顶部

**功能**: 实时显示系统关键指标，每5秒自动更新

**显示内容**:
- **运行时间**: 系统已运行时长（天/小时/分钟）
- **磁盘使用率**: 根分区使用百分比
- **内存使用率**: 系统内存使用百分比
- **CPU使用率**: 整体CPU使用百分比
- **网络速度**: 当前网络实时速率（Mbps）

**数据来源**: `/api/system/status` (轮询间隔: 5秒)

**视觉效果**: 每个指标带有图标，使用不同颜色区分（蓝色主题）

### 2.3 侧边栏

**位置**: 页面左侧固定

**结构**: 分为三个主要分类区块

#### 2.3.1 用户信息区

- 显示当前登录用户名
- 显示设备主机名（可编辑，功能待实现）
- 自动从后端获取设备信息（`/api/device/info`，每60秒刷新）

#### 2.3.2 导航菜单

**系统分类**:
- 概览
- 日志
- 存储管理
- 网络
- 运行中心

**工具分类**:
- 终端
- 文件传输

**ROS分类**:
- ROS 概览
- 通信监控
- 采集与配置
- ROS-AI（开发中）

**交互行为**:
- 点击菜单项切换模块
- 当前激活项高亮显示
- 自动更新面包屑导航

#### 2.3.3 电源控制

**位置**: 侧边栏底部

**功能**:
- 重启系统
- 关闭系统

**权限要求**: 需要管理员权限

**操作流程**:
1. 鼠标悬停显示下拉菜单
2. 点击选择操作
3. 弹出确认对话框
4. 验证管理员权限
5. 验证 CSRF Token
6. 执行电源操作
7. 显示操作结果

**安全措施**:
- 二次确认
- 管理员验证
- CSRF保护

### 2.4 顶部导航栏

**位置**: 主内容区上方

#### 2.4.1 左侧：面包屑导航

- 显示当前位置: `RosDeck > [当前模块名]`
- 自动根据模块切换更新

#### 2.4.2 中央：设备卡片

**显示内容**:
- 设备在线/离线状态（带脉冲动画点）
- 设备主机名

**状态指示器**:
- 在线: 绿色脉冲点
- 离线: 灰色静态点

**数据来源**: `/api/device/info` (60秒刷新)

#### 2.4.3 右侧：功能按钮

**通知按钮**:
- 图标: 铃铛
- 徽章: 显示未读通知数量
- 功能: 显示通知面板（开发中）

**用户卡片**:
- 显示当前用户名
- 显示用户角色（普通用户/管理员）
- 点击显示用户菜单（开发中）

**管理员模式切换**:
- **图标**: 盾牌锁
- **状态显示**:
  - 未激活: "管理员 - 未激活"
  - 已激活: "管理员 - 已激活"（高亮）
- **激活流程**:
  1. 点击按钮
  2. 弹出密码输入框（需要 root 密码）
  3. 验证管理员权限（`/api/auth/verify-admin`）
  4. 验证成功后：
     - 按钮高亮显示
     - 用户角色更新为"管理员"
     - 触发 `rosdeck:admin-mode-change` 事件
     - 所有模块自动刷新并显示管理员功能
- **退出管理员模式**:
  1. 再次点击按钮
  2. 调用 `/api/auth/admin-logout`
  3. UI 恢复普通用户状态
  4. 触发 `rosdeck:admin-mode-change` 事件

**权限控制**:
- 管理员会话有效期: 30分钟
- 会话过期后需要重新验证
- 所有管理员操作需要 CSRF Token

### 2.5 模块加载机制

**加载方式**: 动态异步加载

**加载流程**:
1. 用户点击侧边栏菜单
2. 显示加载动画
3. 卸载当前模块（调用 `window.moduleCleanup()`）
4. 清理当前模块的样式和脚本
5. 加载新模块的 HTML (`modules/{模块路径}/index.html`)
6. 加载新模块的 CSS (`modules/{模块路径}/style.css`)
7. 加载新模块的 JS (`modules/{模块路径}/main.js`)
8. 执行新模块的初始化（调用 `window.moduleInit()`）

**缓存破坏**: 每次加载都使用时间戳参数 `?t={timestamp}`

**错误处理**: 加载失败显示友好的错误页面，提供返回概览按钮

### 3.2 日志模块

**路径**: `modules/logs/`

**模块标识**: `logs`

**功能定位**: journalctl 日志查询与分析

**权限说明**:
- 普通用户: 默认查询限制（100条/次，最多200条）
- 管理员: 更高查询限制

#### 3.2.1 筛选卡片

**优先级过滤**:
- 下拉选择框
- 选项: 默认(自动)、0-7（EMERG到DEBUG）
- 数据来源: `/api/logs/metadata`

**关键字搜索**:
- 文本输入框
- 支持正则表达式
- 实时高亮匹配结果

**时间范围**:
- 起始时间: datetime-local 输入框
- 结束时间: datetime-local 输入框
- 格式: YYYY-MM-DD HH:MM

**加载行数**:
- 数字输入框
- 默认值: 根据用户权限（普通用户100，管理员200）
- 最大值: 由后端限制

**操作按钮**:
- **查询日志**: 执行搜索并加载结果
- **重置**: 清空所有筛选条件并重新查询

**权限徽章**:
- 显示当前用户权限（普通模式/管理员模式）
- 权限不足时显示警告信息

#### 3.2.2 结果卡片

**卡片头部**:
- 摘要文本: 显示已加载日志条数
- 刷新按钮: 使用当前筛选条件重新查询

**日志列表**:

每条日志显示为独立卡片，包含：

**头部**:
- 优先级徽章（带颜色编码）
- 时间戳（本地化格式）

**主体**:
- 日志消息（关键字高亮显示）

**页脚**:
- 单元 (unit): 产生日志的 systemd 单元
- 主机名 (hostname): 日志来源主机
- 进程ID (pid): 产生日志的进程ID

**空状态**:
- 未查询: "请选择条件并点击查询"
- 无结果: "没有符合条件的日志"

**卡片页脚**:
- **加载更多按钮**:
  - 使用游标分页
  - 有更多数据时启用
  - 新数据追加到列表底部
  - 保持当前筛选条件

#### 3.2.3 数据流程

1. 模块初始化时获取元数据（`/api/logs/metadata`）
2. 用户设置筛选条件
3. 点击查询执行搜索（`/api/logs/query`）
4. 服务器返回日志条目和分页游标
5. 渲染日志列表
6. 用户可以加载更多（使用游标）

#### 3.2.4 管理员模式变化

监听 `rosdeck:admin-mode-change` 事件：
- 管理员模式激活: 重新加载元数据，提高查询限制
- 管理员模式退出: 重新加载元数据，降低查询限制

#### 3.2.5 样式特性

- 深色主题设计
- 优先级颜色编码:
  - EMERG/ALERT: 深红
  - CRIT/ERR: 红色
  - WARNING: 橙色
  - NOTICE: 蓝色
  - INFO: 绿色
  - DEBUG: 灰色
- 关键字高亮: 黄色背景
- 响应式布局

#### 3.3.3 存储维护区（管理员）

**访问限制**: 仅管理员模式下可见

**权限指示**:
- 未激活管理员: 显示占位符 + 提示信息
- 已激活管理员: 显示操作面板

**操作面板结构**: 4个操作区块

**操作区1: 安全清理**

- **清理目标**（单选）:
  - 临时目录 (/tmp, /var/tmp)
  - 软件包缓存 (/var/cache/apt)
  - 用户缓存 (~/.cache)
  - ROS 日志 (~/.ros/log)
  - 自定义路径（文本输入）
- **操作按钮**:
  - **预估空间**:
    - 功能: 执行 dry-run，预估可释放空间
    - 不实际删除文件
  - **执行清理**:
    - 倒计时按钮（8秒）
    - 倒计时期间可取消
    - 确认后执行清理
- **结果提示**: 显示预估/实际释放空间
- **API**: `/api/storage/cleanup`

**操作区2: 挂载管理**

- **表单字段**:
  - 设备路径: 如 /dev/sdb1
  - 挂载点: 如 /mnt/data（挂载时必填，卸载时可选）
  - 挂载选项: 如 rw,noatime（可选）
  - 操作类型: 挂载/卸载（单选按钮组）
- **执行按钮**: 倒计时按钮（10秒）
- **结果提示**: 显示操作结果或错误信息
- **API**: `/api/storage/mount`
- **安全提示**: "执行前请核对设备与挂载点"

**操作区3: 分区与格式化**

- **表单字段**:
  - 设备 (整盘): 如 /dev/sdc
  - 操作: 格式化(mkfs) / 清除签名(wipefs)
  - 文件系统: ext4 / xfs / btrfs / vfat
  - 卷标: 可选，最多32字符
  - 额外参数: 可选，如 `-E lazy_itable_init=0`
- **执行按钮**: 倒计时按钮（12秒）
- **结果提示**: 显示操作结果
- **API**: `/api/storage/partition`
- **风险警告**: "⚠️ 高风险操作：执行前请先卸载设备并确认目标"

**操作区4: SMART 检测**

- **表单字段**:
  - 设备: 如 /dev/sda
  - 自检模式:
    - 短检 (约2分钟)
    - 长检 (耗时较久)
    - 运输检测
- **启动按钮**: 倒计时按钮（6秒）
- **获取报告按钮**: 点击加载 SMART 报告
- **报告显示区**:
  - 显示完整的 SMART 诊断信息
  - 包括健康状态、属性值、测试结果
  - 使用 <pre> 标签保持格式
- **API**:
  - 启动检测: `/api/storage/smart`
  - 获取报告: `/api/storage/smart?device={device}`

#### 3.3.4 操作日志

**位置**: 维护区底部

**功能**: 记录所有管理员操作

**日志条目内容**:
- 操作ID (log_id)
- 操作类型（清理/挂载/格式化/SMART）
- 操作参数
- 执行时间
- 操作者
- 状态（started/completed/failed）
- 结果详情

**显示方式**:
- 时间倒序
- 最多显示最近100条
- 失败的操作用红色高亮

#### 3.3.5 倒计时按钮机制

所有高风险操作使用倒计时按钮：

**工作流程**:
1. 用户首次点击按钮
2. 按钮进入倒计时状态（如 8秒）
3. 倒计时期间按钮显示剩余秒数
4. 用户可在倒计时期间再次点击取消
5. 倒计时结束后执行操作
6. 操作完成后重置按钮

**设计目的**: 防止误操作

#### 3.3.6 数据更新策略

- **实时数据**: 每5秒更新（使用率、读写速率）
- **历史数据**: 10分钟滑动窗口，每5秒采样
- **图表更新**: 数据更新时自动重绘
- **分区列表**: 模块激活时加载，切换标签页时刷新

**连接URL**: `ws://{host}/api/terminal/ws` 或 `wss://{host}/api/terminal/ws`

**连接流程**:
1. 模块初始化
2. 获取会话信息（`/api/terminal/session-info`）
3. 创建 WebSocket 连接
4. 连接成功后发送终端尺寸
5. 开始 ping/pong 心跳（每20秒）

**消息格式**: JSON

**客户端 → 服务器**:

```json
// 用户输入
{
  "type": "input",
  "data": "ls -la\n"
}

// 终端大小变化
{
  "type": "resize",
  "cols": 100,
  "rows": 30
}

// 心跳
{
  "type": "ping"
}
```

**服务器 → 客户端**:

```json
// 终端输出
{
  "type": "output",
  "data": "total 48\ndrwxr-xr-x..."
}

// 错误消息
{
  "type": "error",
  "message": "Command execution failed"
}

// 命令被拦截
{
  "type": "command_blocked",
  "command": "rm -rf /",
  "message": "This command is blocked for security reasons"
}

// 命令被允许
{
  "type": "command_allowed",
  "command": "ls -la"
}

// 会话信息
{
  "type": "session_info",
  "username": "openeuler",
  "is_admin": false,
  "admin_session_expires_in": 0
}

// 心跳响应
{
  "type": "pong"
}
```

#### 4.2.4 输入缓冲机制

**问题**: 如果用户在连接建立前输入，输入可能丢失

**解决方案**: 输入缓冲

**工作流程**:
1. 用户输入时检查连接状态
2. 如果已连接: 立即发送
3. 如果未连接: 缓存到 `pendingInput` 缓冲区
4. 缓冲区限制: 4096 字符
5. 连接建立后自动发送缓冲区内容

**缓冲溢出处理**:
- 保留最近的 4096 字符
- 丢弃更早的输入
- 显示警告日志

- 自动重连: 是
- 重连条件: 模块仍然活跃

3. 等待5秒
4. 尝试重新连接
5. 如果成功: 恢复正常
6. 如果失败: 继续重连循环

## 6. 权限与安全

### 6.1 会话管理

#### 6.1.1 基础会话

**登录**:
- 独立的登录页面（未包含在本文档范围）
- PAM 身份验证
- 成功后设置 `session_id` Cookie

**会话持久化**:
- 后端内存存储（重启后失效）
- 无持久化存储（Redis/数据库）
- 生产环境需要外部存储

**会话验证**:
- 每个 API 请求都需要有效的 `session_id`
- 会话过期: 30分钟无活动
- 活动定义: 任何 API 请求

#### 6.1.2 管理员会话

**激活流程**:
1. 用户点击管理员模式按钮
2. 输入 root 密码
3. 后端调用 PAM 验证 root 密码
4. 验证成功设置 `admin_session_id` Cookie
5. 触发前端 `rosdeck:admin-mode-change` 事件

**管理员会话生命周期**:
- 独立于基础会话
- 有效期: 30分钟
- 自动延长: 每次管理员操作
- 手动退出: 调用 `/api/auth/admin-logout`

**管理员权限检查**:
- 所有管理员操作需要验证 `admin_session_id`
- 会话过期自动降级为普通用户

### 6.2 CSRF 保护

#### 6.2.1 Token 生成

**时机**: 用户登录或首次访问

**存储**:
- 后端: 内存中的会话数据
- 前端:
  - `<meta name="csrf-token">` 标签
  - sessionStorage (`rosdeck_csrf_token`)

**刷新策略**:
- 页面加载时自动同步
- 缺失时调用 `/api/csrf-token` 获取

#### 6.2.2 Token 验证

**保护范围**: 所有状态修改操作（POST, PUT, DELETE, PATCH）

**验证方式**:
- 客户端在请求头中包含: `X-CSRF-Token: {token}`
- 服务器验证 token 与会话中的 token 一致

**失败处理**:
- 返回 403 Forbidden
- 前端提示: "CSRF Token 无效，请刷新页面"

### 6.3 文件访问控制

#### 6.3.1 普通用户

**访问范围**: 用户主目录（`$HOME`）

**限制**:
- 不能访问主目录外的文件
- 不能向上导航超出主目录
- 路径规范化（防止 `../` 逃逸）

**文件操作**:
- 浏览: 主目录及子目录
- 上传: 仅限主目录
- 下载: 仅限主目录
- 删除: 仅限主目录

#### 6.3.2 管理员

**访问范围**: 完整文件系统（`/`）

**警告**:
- 在敏感目录显示警告横幅
- 敏感目录: /etc, /bin, /sbin, /usr, /boot, /var

**文件操作**:
- 浏览: 全部可读目录
- 上传: 全部可写目录
- 下载: 全部可读文件
- 删除: 全部可写文件

**安全建议**:
- 在敏感目录操作前二次确认
- 记录所有管理员文件操作

### 6.4 终端安全

#### 6.4.1 命令黑名单

**后端实现**: 拦截危险命令

**拦截机制**:
- 解析用户输入
- 匹配黑名单规则
- 拒绝执行并通知用户

**黑名单示例**:
- `rm -rf /`
- `mkfs.*` (格式化命令)
- `dd if=/dev/zero ...`
- 其他危险的系统修改命令

**通知方式**:
- 终端显示拦截消息
- 记录到操作日志
- 不执行命令

#### 6.4.2 会话隔离

**隔离机制**:
- 每个 WebSocket 连接对应独立的 PTY（伪终端）
- 进程隔离
- 环境变量隔离

**权限继承**:
- 终端进程以后端服务用户身份运行
- 不自动提升权限
- 管理员会话不影响终端权限

#### 6.4.3 超时保护

**后端超时**:
- 命令执行超时: 30秒（可配置）
- 超时自动终止命令
- 返回超时错误

**连接超时**:
- 心跳间隔: 20秒
- 3次心跳失败断开连接
- 防止僵尸连接

### 6.5 存储操作安全

#### 6.5.1 操作权限

**所有存储维护操作需要**:
1. 管理员会话
2. CSRF Token
3. 倒计时确认

**后端验证**:
- 依赖项验证（如 `smartctl` 是否安装）
- 命令参数白名单验证
- 路径规范化

#### 6.5.2 倒计时按钮

**目的**: 防止误操作

**工作流程**:
1. 首次点击: 启动倒计时
2. 倒计时期间: 显示剩余秒数，可取消
3. 倒计时结束: 自动执行操作
4. 再次点击（倒计时期间）: 取消操作

**倒计时时长**:
- 清理操作: 8秒
- 挂载/卸载: 10秒
- 格式化: 12秒
- SMART 检测: 6秒

#### 6.5.3 操作日志

**记录内容**:
- 操作ID (log_id)
- 操作类型
- 操作参数
- 执行时间
- 操作者（用户名）
- 状态（started/completed/failed）
- 结果详情

**日志存储**:
- 内存存储（最多100条）
- 服务重启后清空
- 生产环境建议持久化到文件或数据库

**日志用途**:
- 审计追踪
- 故障排查
- 安全分析

### 6.6 网络配置安全

#### 6.6.1 IP 配置

**权限**: 仅管理员

**验证**:
- IP 地址格式验证
- 子网掩码/前缀验证
- 网关地址验证（可选）

**持久化选项**:
- 临时配置: 使用 `ip` 命令（重启失效）
- 持久配置: 写入 netplan（重启保留）

**风险提示**:
- 错误配置可能导致网络连接丢失
- 建议先临时测试，确认无误后持久化

#### 6.6.2 网络诊断

**工具**: Ping

**限制**:
- 次数限制: 1-20次
- 超时限制: 每个包5秒
- 总超时: 120秒

**安全**:
- 命令参数白名单
- 防止命令注入

### 6.7 ROS 操作安全

#### 6.7.1 参数修改

**权限**: 管理员

**风险**:
- 错误参数可能导致节点异常
- 某些参数可能影响系统稳定性

**建议**:
- 修改前记录原始值
- 提供导出/导入快照功能
- 关键参数修改前警告

#### 6.7.2 录制与回放

**权限**: 管理员

**资源考虑**:
- 录制可能占用大量磁盘空间
- 回放可能产生高网络/CPU负载

**保护机制**:
- 大小限制
- 时长限制
- 监控录制状态
- 允许随时停止

#### 6.7.3 Launch 管理

**权限**: 管理员

**风险**:
- Launch 文件可执行任意命令
- 恶意 launch 文件可能危害系统

**安全建议**:
- 仅信任已知来源的 launch 文件
- 使用独立用户运行 ROS 任务
- 限制 launch 进程的系统权限

- `rosdeck_csrf_token`: CSRF Token（string）

#### Cookies
- `session_id`: 基础会话ID（HttpOnly, SameSite=Lax）
- `admin_session_id`: 管理员会话ID（HttpOnly, SameSite=Lax）

### 8.4 浏览器兼容性

**必须支持的特性**:
- ES6+ 语法
- Fetch API
- WebSocket
- localStorage / sessionStorage
- CSS Grid / Flexbox
- CSS 自定义属性（变量）

**可选特性**:
- Service Worker（离线支持，未实现）
- Web Notifications（通知，未实现）

### 8.5 已知限制

1. **会话持久化**: 会话和 CSRF Token 仅存在内存，服务重启后失效
2. **多实例部署**: 不支持负载均衡，会话不共享
3. **大文件上传**: 限制 50MB，无断点续传
4. **WebSocket 断线**: 重连有5秒延迟，期间无法操作
5. **浏览器限制**: 不支持 IE，需要现代浏览器
6. **移动端**: 响应式设计，但某些功能（如终端）在移动端体验不佳
7. **国际化**: 所有文本硬编码为中文，无多语言支持
8. **离线模式**: 无 Service Worker，不支持离线使用
